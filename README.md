## 🧪 Troubleshooting Tips  

### App Won't Install  
- Make sure you have "Install from unknown sources" enabled for your browser or file manager.  
- Check that you have enough free storage space (at least 2GB).  

### Captions Lag or Delay  
- Close other heavy apps running in the background.  
- Restart Hearth to free up memory.  

### Translation Seems Off  
- Speak clearly or adjust the audio volume.  
- Make sure you've selected the correct source and target languages in the app settings.  

### App Crashes on First Run  
- Reboot your phone and try again.  
- If the issue persists, uninstall and reinstall the latest version.
